# Neumorphism UI documentation

This package serves the localized documentation, shared-source previews, and generated registry endpoints.
See [the root README](../README.md) for installation, supported versions, and development commands, and [QUALITY.md](../QUALITY.md) for verification scope and remaining product work.

Run `npm ci` in both `registry` and `docs` before starting development. The docs dev/build scripts generate and synchronize the registry first. Never edit `public/r`, `app/theme.css`, or the generated theme bootstrap by hand.
